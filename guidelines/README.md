# Annotation Guidelines

## Project Title
Financial Document Classification and Entity Extraction

## Purpose
This folder contains the annotation guidelines and reference materials for the financial document annotation project.

## Main Objectives
1. Classify financial documents into the correct categories.
2. Identify and extract important financial entities.
3. Normalize extracted values.
4. Maintain consistent annotation quality.
5. Follow the project annotation rules.

## Project Categories
- Bank Statements
- Commercial Invoices
- Income Tax Returns
- Loan Agreements
- Insurance Policies
- Regulatory Filings
- Payment Receipts
- Financial Statements
