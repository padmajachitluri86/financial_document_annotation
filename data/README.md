# Financial Document Dataset

This folder contains the financial documents and annotation datasets used in this project.

## Folder Structure

- gold_standard/ – Final reviewed annotations.
- raw_documents/ – Original financial documents.
- iaa_study/ – Data used for inter-annotator agreement analysis.

## Dataset

Total required documents: 200

The dataset covers eight financial document categories.

## Important

Use anonymized or approved project documents. Do not upload private bank statements, PAN details, or other sensitive personal information to a public repository.
